# Mise en service

1. Publier la branche `design-b-mobile` via GitHub Pages.
2. Vérifier HTTPS.
3. Contrôler le résultat de la CI.
4. Sur téléphone, tester :
   - installation PWA ;
   - géolocalisation ;
   - Plan / Satellite / OACI ;
   - météo réelle ;
   - import du ZIP GeoGM/SIA ;
   - espaces et aérodromes ;
   - VAC/AIP ;
   - NOTAM / SUP AIP ;
   - dictée ;
   - export / partage d'une mission.
5. Lors d'un nouveau cycle AIRAC, importer le nouveau ZIP GeoGM/SIA depuis MENS → Espace.
